Restrictions on autoboxing and conversion of primitives and wrappers
Java allows automatic unboxing and then widening the resulting primitive value to a different primitive type (following the samerules as the ones for primitive types) but it does not autobox the widened value. For example: 
int i = 10; Integer I = 10; Double D = 10.0; double d = i; //ok, implicit widening of int value to double d = I; //ok, Java unboxes I to int and then widens the value to double automatically
However, the following code fails to compile:
Double d = i; //not ok, requires widening and then autoboxing d = (Double) i; //not ok, requires widening and then autoboxing d = I; //not ok, requires unboxing, widening, and then autoboxing Short s = (Short) I; //not ok, requires unboxing, narrowing, and then autoboxing s = (Short) i; //not ok, requires narrowing and then autoboxing

4. Unary numeric promotion - If the type of an operand to a unary operator is smaller than int, the operand will automatically bepromoted to int before applying the operator. Example: Given, char x = 97, y = 'b'; the statement char z =(char)x + (char)y; will not compile because the type of the value generated by the expression (char)x +(char)y will be an int ( with value 195) and not a char.5. Binary numeric promotion - Both the operands of a binary operator are promoted to an int but if any of the operands is largerthan an int, the other operand is promoted to the same type as the type of the larger one.6. Numeric promotion doesn't happen for wrapper types but compound operators such as ++ and -- can be applied to numericwrapper type variables because of unboxing and implicit casting that happens with these operators.7. Value of a smaller type can be assigned to a variable of a larger type without a cast. 1.3 Math API ☝
1. public final class Math extends Object - The class java.lang.Math contains methods for performing basic numeric operationssuch as the elementary exponential, logarithm, square root, and trigonometric functions.2. Important methods: int/long/float/double abs(int/long/float/double )long/int round(double/float )int/float/long/double min/max(int/float/long/double, int/float/long/double)Observe the parameter and return types of these methods.3. double random() - Returns a double value with a positive sign, greater than or equal to 0.0 and less than 1.0. E.g. int x = (int) Math.random()*9; This will always assign 0 to x because the casting operator has higherprecedence than the multiplication operator. To get an int value between 0 (inclusive) and 9 (exclusive) do this: (int)(Math.random()*9);4. There is also a Random class in java.util package that can be used to create an unending stream of random numbers. E.g.DoubleStream ds = new Random().doubles();
