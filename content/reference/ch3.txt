3.1 if/else and ternary ☝
An if/else statement can have a single statement or multiple statements. E.g.
if(condition) single statement; if(condition){ multiple statements } if(condition) single statement; else single statement; if(condition){ block of statements }else { multiple statements } 
if(condition) else statement or block; //not valid if(condition){ } else statement or block; // valid condition must be a boolean expression, such as i==2, methodThatReturnsABoolean(), and booleanVar.
Ternary operator :?
1. condition? operand1 : operand 22. Works alomost like if/else3. short circuiting4. Has lowest prcedence except assignment operators, and lambda operators.

3.2 switch statements and expressions ☝
1. A switch can be used to create a statement or an expression. A statement does not have a return value while an expression does.2. Java 22+ allows unnamed variables to be used in switch patterns. E.g.: switch(obj){ case String _ -> println("str"); default ->println("unk"); }3. Both a switch statement and a switch expression can be written using the old ( uses : ) as well as the new syntax (uses -> ).4. Java 21+ allows the switch expression type to be anything except long, float, double, or boolean. Thus, it can bebyte, short, char, int and their wrapper types, String, enums, and any object reference (including a reference towrapper types Long, Float, Double, and Boolean).5. Java 21+ allows null as a case constant.6. switch statements and expressions that use the new syntax do not have fall through. break is allowed only when a block ofstatements is associated with a case but it is redundant, otherwise it is prohibited in the new syntax.7. When a switch selector expression uses a reference type, it becomes a switch with pattern matching. Such switch blocks canuse case with guards.8. Only switch statements without pattern matching written using old as well as new syntax are allowed to be non-exhaustive.Switch expressions and switch statements with pattern matching must be exhaustive.

The label of a labelled break/continue must be associated with an encompassing loop (any kind of loop)
